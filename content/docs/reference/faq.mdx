# FAQ

## General

**What is ProDocs?**

ProDocs is an integrated documentation ecosystem comprising ProDoc (authoring), ProFeed (feedback), ProAssist (AI assistant), ProAPI (API governance), and ProInsights (analytics).

**Who is this documentation for?**

Technical writers, documentation engineers, developer relations teams, and product managers evaluating documentation platform capabilities.

**Is this a production SaaS product?**

This portal is a portfolio demonstration of enterprise documentation patterns and integrated product workflows. Live demo apps for ProFeed and ProInsights are available from the product pages.

## ProDoc

**What content formats does ProDoc support?**

MDX with frontmatter, Mermaid diagrams, admonitions, tabs, code blocks with copy, and OpenAPI-linked API reference.

**How is navigation structured?**

Navigation follows Docusaurus-style categories: Getting Started, Platform Overview, Products, Documentation Samples, and Reference.

## ProFeed & ProInsights

**How does feedback reach triage teams?**

Readers submit feedback via the documentation widget. Submissions appear in ProFeed with page path and section anchor context, then aggregate in ProInsights for prioritization.

## Documentation samples

**Are the sample articles based on real products?**

Samples use realistic enterprise scenarios (insurance claims, payments, ERP, logistics) to demonstrate technical writing deliverables—not fictional filler.
