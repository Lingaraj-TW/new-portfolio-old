# Glossary

| Term | Definition |
| ---- | ---------- |
| **Documentation Intelligence Loop** | Continuous cycle where ProDoc publishes content, ProFeed captures feedback, and ProInsights drives improvements. |
| **ProDoc** | Documentation authoring and publishing platform (MDX, search, versioning). |
| **ProFeed** | Feedback collection and triage for documentation pages. |
| **ProAssist** | AI assistant with citation-based answers over your doc corpus. |
| **ProAPI** | Developer portal with OpenAPI reference, SDKs, and governance standards. |
| **ProInsights** | Analytics for page views, search success, feedback trends, and content health. |
| **Correlation ID** | Trace identifier attached to API requests and support tickets. |
| **Tenant** | Isolated customer environment with dedicated configuration and data. |
| **RBAC** | Role-based access control for admin and contributor permissions. |
| **IdP** | Identity provider used for SSO authentication. |
