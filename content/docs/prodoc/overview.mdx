# ProDoc Overview

## What is ProDoc?

ProDoc is a documentation platform designed to:

- Create developer-friendly documentation
- Support docs-as-code workflows
- Enable structured and scalable content

## Key features

- **Docs-as-code** (Git-based workflow)
- **API documentation support**
- **Versioning**
- **Modular content structure**
- **Developer-first navigation**

## Core modules

- Content management
- API documentation
- Versioning
- Theming & UI
- Search & navigation

## Example use case

A developer visits ProDoc to integrate an API using structured guides and references. If they get stuck, they submit section-level feedback through ProFeed, which flows into ProInsights and back into improved docs.
