# Portfolio overview

Welcome—this site is both a **technical writing portfolio** and a working **documentation product demo**. I am Linga Raj M, a Senior Technical Writer with eight years of experience translating complex healthcare and SaaS platforms into manuals, API references, SOPs, and multimedia learning assets.

## What you can explore

- **Work samples** in this sidebar mirror the types of deliverables I ship in production: API guides, release notes, and knowledge-base patterns.
- **Customer feedback** is available on every documentation page through the floating control. Reviewers can combine helpful votes, star ratings, text highlights, pins on the page, tagged authors/teams, and attachments (screenshots, PDFs, or text files when the service role is configured).
- **Customer portal** (`/portal/login`) lists all submitted feedback for stakeholders who need a cross-page view (MVP: full list for authenticated customer users).
- **Admin triage** (`/admin/login`) lets documentation owners update workflow status under Supabase row level security.

## How to give me signal on this portfolio

Use the feedback widget to comment on clarity, structure, or gaps—especially if you are hiring for remote documentation work. Concrete examples (quotes, screenshots, or pins) help me respond quickly.

## Section anchors

Headings on every page expose stable anchors. Choose a section in the feedback control to attach your note to the exact passage you mean.
