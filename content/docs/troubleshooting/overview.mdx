# Troubleshooting

## Feedback not captured

- Confirm you're on a `/prodoc/...` page (the widget only renders there).
- Confirm Supabase env vars are configured.
- Check allowed origins if posting cross-domain.

## Analytics not showing

- Ensure feedback rows exist (submit a test feedback).
- Confirm your ProInsights page loads and can query the database.

## API integration issues

- Ensure `/api/feedback` is reachable from the docs domain.
- If attachments/edit flows are needed, configure the service role key.
