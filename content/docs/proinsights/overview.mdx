# ProInsights Overview

## What is ProInsights?

ProInsights is a documentation analytics platform that transforms feedback and usage data into actionable insights.

## What it analyzes

- Page views (where available)
- Drop-offs and friction signals
- Search queries (where available)
- Feedback trends (helpful vs not helpful, stars)
- Error-prone sections (via section anchors + highlights)

## Key features

- Dashboard visualization
- Feedback analysis
- Content performance scoring
- Trend identification
- Improvement recommendations

## Data flow

ProDoc + ProFeed → Data aggregation → ProInsights dashboard
