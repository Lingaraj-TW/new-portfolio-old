# Submit Your First Feedback in 10 Minutes

Learn how to submit your first piece of documentation feedback using the **ProFeed** widget embedded in the ProDoc portal. This tutorial covers locating the widget, attaching feedback to a specific section, and tracking your submission through triage.

**Duration:** 10 minutes  
**Audience:** Technical writers, product managers, engineers, and support agents

## Learning objectives

After completing this tutorial, you will be able to:

1. Locate and open the ProFeed feedback widget on any documentation page
2. Select a section anchor to attach feedback to a specific passage
3. Submit feedback with a category, description, and optional screenshot
4. Track your submission status in the ProFeed dashboard
5. Understand how feedback flows into the documentation triage workflow

## Step-by-step summary

### 1. Open any documentation page

Navigate to any page in the ProDoc portal — for example, this page or the [Installation Guide](/prodoc/documentation-samples/installation-guide).

### 2. Click the Feedback widget

The floating **Feedback** button appears in the bottom-right corner of every page. Click it to open the feedback panel.

<Screenshot
  alt="ProFeed feedback widget button in bottom-right corner of documentation page"
  caption="Figure 1 — The Feedback widget is available on every ProDoc page."
/>

### 3. Select a section anchor

The widget displays section headings from the current page. Select the heading closest to the content you want to comment on. This anchors your feedback to the exact passage.

<Tip title="Why anchors matter">
Anchored feedback routes directly to the author responsible for that section. Unanchored feedback goes to a general triage queue and takes longer to resolve.
</Tip>

### 4. Choose a category and write your feedback

| Category | When to use |
| -------- | ----------- |
| **Accuracy** | Information is incorrect or outdated |
| **Clarity** | Content is confusing or poorly structured |
| **Missing info** | A topic needs coverage that is not present |
| **Broken link** | A hyperlink returns an error or wrong destination |
| **Suggestion** | General improvement idea |

Write a clear description. Include what you expected to find and what you found instead.

### 5. Attach a screenshot (optional)

Click **Attach screenshot** to capture the current page viewport. Screenshots help authors reproduce the issue quickly.

### 6. Submit and track

Click **Submit Feedback**. You receive a confirmation with a feedback ID (format: `FB-2026-XXXXX`).

Track status in the ProFeed dashboard at `/profeed` or via email notifications at each triage stage:

```
Submitted → Triaged → Assigned → In Progress → Resolved
```

## Transcript

**[0:00] Introduction**

Welcome to this tutorial on submitting your first feedback in ProDoc. ProFeed is the feedback layer built into every documentation page. Whether you spot a typo, a broken link, or a missing section, ProFeed lets you tell the documentation team exactly where the issue is.

**[0:45] Locating the widget**

On any ProDoc page, look for the Feedback button in the bottom-right corner. It stays visible as you scroll. Click it to open the feedback panel.

**[2:10] Selecting a section anchor**

The panel lists section headings from the current page. Select the heading nearest to the content you want to comment on. For example, if the installation prerequisites are unclear, select the "Prerequisites" heading. This anchors your feedback so the right author sees it.

**[4:30] Writing effective feedback**

Choose a category that matches your issue. In the description field, be specific: quote the confusing sentence, describe what you expected, and suggest a fix if you have one. Good feedback saves the author time and gets your issue resolved faster.

**[6:15] Attaching a screenshot**

Click Attach screenshot to capture what you see on screen. This is especially helpful for layout issues, broken rendering, or error messages. The screenshot attaches to your feedback row automatically.

**[7:45] Submitting and tracking**

Click Submit Feedback. You will see a confirmation with your feedback ID. You can track progress in the ProFeed dashboard. The documentation team triages submissions daily and assigns them to authors. You will receive email updates when your feedback is resolved.

**[9:30] Best practices recap**

Always anchor feedback to a section. Be specific in your description. Attach screenshots when visual context helps. And check the ProFeed dashboard if you want to see how your team is using feedback to improve documentation.

**[10:24] End**

That is it — you have submitted your first feedback. Explore the related articles below to learn how feedback flows through triage and into documentation updates.
