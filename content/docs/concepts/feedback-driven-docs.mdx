# Feedback-driven docs

Feedback-driven docs make improvement measurable.

## What to capture

- helpful / not helpful outcomes
- star ratings for page quality
- section-level context (anchors, highlights, pins)
- user explanations in plain language

## How ProDocs enables this

ProFeed captures feedback while the user is still in context, and ProInsights turns it into a prioritized backlog of doc improvements.
