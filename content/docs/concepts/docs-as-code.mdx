# Docs-as-code

Docs-as-code treats documentation like software:

- stored in a repo
- reviewed via pull requests
- versioned and released

## Benefits

- Consistency via templates and structure
- Traceability: every change has history
- Faster iteration based on ProFeed + ProInsights signals
