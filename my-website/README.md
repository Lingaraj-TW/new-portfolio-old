# ProDoc (Docusaurus)

This folder contains the ProDoc documentation site built with Docusaurus.

## Local development

```bash
cd my-website
npm install
npm run start
```

## Deploy on Vercel (monorepo)

- Create a second Vercel project whose **Root Directory** is `my-website/`.
- The Next.js app stays as a separate Vercel project whose root is the repo root.
